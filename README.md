# Mega Project 2026

A hands-on **RTL / Digital Design / VLSI** project focused on implementing, verifying, and comparing different hardware architectures in **Verilog**.

The project is being developed incrementally, starting with fundamental adder architectures and moving toward faster parallel-prefix designs.

## 1. Ripple Carry Adder (RCA)

The **4-bit Ripple Carry Adder** is built using four 1-bit full adders connected in series. The carry generated by each stage propagates to the next stage.

```text
A0, B0, Cin → FA0 → C1
A1, B1, C1  → FA1 → C2
A2, B2, C2  → FA2 → C3
A3, B3, C3  → FA3 → Cout
```

### Files

- `RAC/RAC_4bit.v` — 4-bit RCA implementation
- `RAC/RAC_4bit_tb.v` — testbench
- `RAC/output.vcd` — simulation waveform
- `RAC/rac_4bit_tb.vcd` — waveform dump

### Verification

The testbench exercises the input combinations and compares the DUT output with the expected arithmetic result.

---

## 2. Carry Look-Ahead Adder (CLA)

The **4-bit Carry Look-Ahead Adder** reduces carry propagation by calculating carries using **generate (G)** and **propagate (P)** signals.

```text
P_i = A_i XOR B_i
G_i = A_i AND B_i
```

The current CLA is implemented as a **gate-level Verilog design** using XOR, AND, OR, and buffer gates.

### Files

- `CLA/CLA_4bit.v` — 4-bit gate-level CLA
- `CLA/CLA_4bit_tb.v` — exhaustive testbench
- `CLA/CLA_4bit_gate_level.vcd` — simulation waveform

### Verification

The testbench checks all **512 possible combinations** of two 4-bit operands and carry-in, then compares the expected 5-bit result with `{cout, sum}`.

## 3. Kogge–Stone Adder (KSA) — Planned

The next architecture planned for this project is a **4-bit Kogge–Stone Adder**, a parallel-prefix adder intended to calculate carry signals with low logic depth.

The KSA will extend the project from conventional carry-based designs toward **parallel-prefix architectures**.

### Planned Work

- 4-bit Kogge–Stone RTL implementation
- Dedicated testbench
- Exhaustive functional verification
- VCD waveform generation
- Comparison with RCA and CLA
- Logic-depth and delay analysis
- Area analysis after synthesis
- Power / Performance / Area / Congestion (**PPAC**) analysis at a later stage

## Verification Flow

```text
RTL Design
    ↓
Testbench
    ↓
Simulation
    ↓
Functional Comparison
    ↓
Waveform Analysis
```

The project emphasizes **exhaustive functional verification** for the current 4-bit adder designs rather than relying only on a small set of manually selected vectors.

This project is intended to build practical understanding of:

- Gate-level modeling

- Parallel-prefix adder architectures
- Hardware architecture comparison
- Timing and implementation-oriented analysis
